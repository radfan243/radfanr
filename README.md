# RADFANR | رادفانر

أول منصة عربية لبيع المنتجات الرقمية والملموسة — يقدر أي شخص يفتح متجره الخاص ويبيع منتجاته بسهولة وأمان.

## المميزات
- فتح متجر مجاني لأي مستخدم
- بيع منتجات رقمية: كتب إلكترونية، دورات، قوالب، دعوات
- بيع منتجات ملموسة تُشحن للعميل
- محفظة داخلية لكل بائع + محفظة عمولة للمنصة
- دعم طرق دفع متعددة: PayPal, Mastercard, حوالات بنكية (الكريمي، القطيبي)
- دعم متعدد اللغات (عربي / إنجليزي)
